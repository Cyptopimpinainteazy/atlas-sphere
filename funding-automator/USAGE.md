Usage and integration notes

- Set environment variables to actually send messages: `N8N_WEBHOOK_URL`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, or `SMTP_TO` for quick testing.
- For n8n flows, follow docs/n8n.md to receive and process promoter payloads.
- For programmatic Google searches use an official API like Google Custom Search (don't scrape directly).
