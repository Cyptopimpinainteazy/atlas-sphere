# Brand & Voice Generator

Use this skill to turn loose brand ideas into a reusable source of truth.

## Workflow

1. Capture the user's audience, offer, differentiators, and existing style constraints.
2. Produce a compact brand system covering voice, messaging, typography, color, and visual rules.
3. Write artifacts that other skills can reuse: brand summary, tone guide, approved phrases, banned phrases, and visual tokens.
4. Keep the output modular so decks, docs, and videos can load only the sections they need.

## Output Rules

- Prefer small, reusable files over one long narrative.
- Separate voice guidance from visual rules.
- Record explicit defaults and edge cases so other skills can apply the brand consistently.
- If the user already has a brand doc, extend it instead of replacing it.
