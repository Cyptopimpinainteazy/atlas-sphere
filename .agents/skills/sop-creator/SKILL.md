# SOP Creator

Use this skill to turn a process into an operational document that people can follow quickly.

## Workflow

1. Define the task, owner, trigger, and expected outcome.
2. Break the work into clear steps with prerequisites and decision points.
3. Add verification checks, rollback paths, and common failure cases.
4. Format the result for rapid scanning: short sections, numbered steps, explicit warnings.

## Output Rules

- Prefer action verbs and concrete conditions.
- State who does the task and when.
- Include success criteria and troubleshooting.
- Keep long background context out of the SOP unless it changes the operator's decisions.
