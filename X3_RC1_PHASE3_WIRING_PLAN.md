# X3 RC-1 Phase 3: Wire Cross-Chain GPU Validator (EVM/SVM State-Root Validation)

**Scope**: Connect EVM + SVM cross-chain state-root validation to runtime API and pallet-x3-verifier.  
**Estimated duration**: 2–3 days  
**Blocking**: Phase 4 (Cross-VM bridge runtime binding)  
**Status**: Ready for execution  

---

## Phase 3 Objective

Enable X3 validators to accept EVM (Ethereum, Arbitrum, Base, Polygon, etc.) and SVM (Solana) finalized state-root proofs generated by GPUs, with automatic CPU fallback when GPUs are unavailable. This unblocks cross-chain atomic settlement and enables the bridge relayer service in Phase 4.

### 3.2 Cross-Chain GPU Validator Public API (crates/cross-chain-gpu-validator/src/lib.rs)

**Location**: End of file (after existing modules), add public validation functions + CPU fallback.

```rust
// ─────────────────────────────────────────────────────────────────
// Public GPU Validation Interface
// ─────────────────────────────────────────────────────────────────

pub use crate::cross_chain_state_root_api::{
    EvmHeaderProof, SvmHeaderProof, CrossChainProofBatch,
    ProcessorType, ProofType, CrossChainValidationStatus,
};

/// Validate EVM header (Keccak256-based)
/// Falls back to CPU if GPU unavailable
pub async fn validate_evm_header(
    block_number: u64,
    block_hash: [u8; 32],
    state_root: [u8; 32],
    orchestrator: Arc<RwLock<SwarmOrchestrator>>,
) -> Result<EvmHeaderProof, ValidationError> {
    let orch = orchestrator.read().await;
    
    // Try GPU path first
    if let Some(gpu_validator) = orch.get_evm_validator() {
        match gpu_validator.validate_header(block_number, block_hash, state_root).await {
            Ok(proof) => {
                log::info!(
                    "✓ EVM header validated via GPU (block: {}, processor: {:?})",
                    block_number, proof.processed_by
                );
                return Ok(proof);
            }
            Err(e) => {
                log::warn!("GPU EVM validation failed: {}, falling back to CPU", e);
            }
        }
    }
    
    drop(orch);
    
    // CPU fallback (deterministic)
    cpu_fallback::validate_evm_header_cpu(block_number, block_hash, state_root)
        .await
        .map_err(|e| ValidationError::CpuFallbackFailed(e.to_string()))
}

/// Validate SVM header (SHA256 + Secp256k1-based)
/// Falls back to CPU if GPU unavailable
pub async fn validate_svm_header(
    slot: u64,
    block_hash: [u8; 32],
    state_root: [u8; 32],
    orchestrator: Arc<RwLock<SwarmOrchestrator>>,
) -> Result<SvmHeaderProof, ValidationError> {
    let orch = orchestrator.read().await;
    
    if let Some(gpu_validator) = orch.get_svm_validator() {
        match gpu_validator.validate_header(slot, block_hash, state_root).await {
            Ok(proof) => {
                log::info!(
                    "✓ SVM header validated via GPU (slot: {}, processor: {:?})",
                    slot, proof.processed_by
                );
                return Ok(proof);
            }
            Err(e) => {
                log::warn!("GPU SVM validation failed: {}, falling back to CPU", e);
            }
        }
    }
    
    drop(orch);
    
    // CPU fallback
    cpu_fallback::validate_svm_header_cpu(slot, block_hash, state_root)
        .await
        .map_err(|e| ValidationError::CpuFallbackFailed(e.to_string()))
}

/// Verify CPU fallback matches GPU result (determinism check)
pub async fn verify_determinism(
    gpu_result: &EvmHeaderProof,
    cpu_result: &EvmHeaderProof,
) -> Result<bool, ValidationError> {
    // All fields must match except ProcessorType
    let matches = gpu_result.block_number == cpu_result.block_number
        && gpu_result.block_hash == cpu_result.block_hash
        && gpu_result.state_root == cpu_result.state_root
        && gpu_result.proof_hash == cpu_result.proof_hash;
    
    if !matches {
        log::error!(
            "⚠️  GPU/CPU determinism check FAILED for EVM block {}",
            gpu_result.block_number
        );
    }
    
    Ok(matches)
}

#[derive(Debug)]
pub enum ValidationError {
    GpuNotAvailable,
    InvalidBlockHeader,
    CpuFallbackFailed(String),
    DeterminismViolation,
}
```

```rust
    module.register_method("validate_evmHeader", move |params, _| {

            .map_err(|e| jsonrpsee::core::Error::ParseError(e.to_string()))?;
```

## 5. Determinism & CPU Fallback

**Critical requirement**: GPU and CPU results must be byte-identical for the same input.

Implementation strategy:
1. GPU path computes proof via CUDA/Metal kernels
2. CPU path recomputes using pure Rust (sha256, keccak256 crates, secp256k1-zkp)
3. On mismatch: log error, emit metric `cross_chain.determinism_failure`, do NOT accept proof
4. Fallback is **not** "use CPU instead if GPU fails"—fallback is "use CPU if GPU unavailable" (different scenario)
