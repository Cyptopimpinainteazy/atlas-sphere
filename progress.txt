
# Session: Current — Fix sp-io / WASM panic_impl + x3-external-chains + x3-bot

## ✅ ROOT CAUSES IDENTIFIED & FIXED

### Problem: Workspace failed to compile with `error[E0152]: found duplicate lang item panic_impl`
- **Root Cause 1**: `crates/x3-common/Cargo.toml` declared `serde = { version = "1.0", features = ["derive"] }` without `default-features = false`, enabling `serde/std` (which defines `std::panic`) in WASM builds and conflicting with `sp-io`'s `#[panic_handler]`
- **Root Cause 2**: `crates/x3-integration/Cargo.toml` did not set `default-features = false` on `x3-common`, causing `x3-common/std` to be active in WASM — which in turn activated `serde/std`
- **Fix**: Added `default-features = false` to both serde in `x3-common` and `x3-common` dep in `x3-integration`; added `x3-common/std` propagation to `x3-integration`'s `std` feature

### Problem: `crates/x3-integration/src/executor.rs` failed in no_std WASM
- `format!` macro not in scope (needed `alloc::format`)
- `MiniValue::to_bytes()` was private but called from executor
- **Fix**: Added `format` to alloc imports in `executor.rs`; made `MiniValue::to_bytes()` pub in `mini_x3.rs`

### Problem: `x3-external-chains` — `could not find rpc_http in crate root`
- `crates/external-chains/src/chains/base.rs` called `crate::rpc_http::post_json` but `rpc_http` was not declared as a module in `lib.rs`
- **Fix**: Added `pub mod rpc_http;` to `crates/external-chains/src/lib.rs`

### Problem: `x3-external-chains` — `non-exhaustive patterns: ParseError not covered`
- `Display` impl for `ExternalChainError` was missing the `ParseError(Vec<u8>)` match arm
- **Fix**: Added `ParseError` arm to the `fmt` match in `crates/external-chains/src/error.rs`

### Problem: `x3-bot` — `missing field sequence_nonce in initializer of AtomicPair`
- `AtomicPair` struct gained a new required field `sequence_nonce: u64` but the initializer in `crates/x3-bot/src/executor.rs` wasn't updated
- **Fix**: Added `sequence_nonce: 0` to the `AtomicPair { ... }` initializer
