# BMAD Next Story

Get the next story to implement from the sprint backlog.

## Usage

Simply run this command to:
- Find the next "ready-for-dev" story
- Display its full content
- Provide implementation guidance

The command reads from `_bmad-output/implementation-artifacts/sprint-status.yaml`

## Output

Returns the full story markdown file including:
- Acceptance criteria
- Technical implementation notes
- Definition of done checklist
