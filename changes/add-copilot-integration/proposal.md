## Why
Integrate Copilot to assist with OpenSpec development by leveraging its code generation and completion capabilities. Copilot can help with writing spec content, code implementations, and documentation, improving efficiency and consistency.

## What Changes
- Integrate Copilot into the development workflow
- Utilize Copilot for generating spec content, code implementations, and documentation
- Establish gfrontend/uidelines for when and how to use Copilot effectively

## Impact
- Improved development efficiency and consistency
- Reduced manual effort for writing specs and code
- Potential for faster iteration and higher quality output
