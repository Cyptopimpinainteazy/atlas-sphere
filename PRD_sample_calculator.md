# Ralph Test Project - Sample PRD

## Overview
This is a sample Product Requirements Document (PRD) to test the Ralph extension. Ralph will autonomously work through these tasks using GitHub Copilot in a loop.

## Tasks
- [ ] Create a simple Python calculator module with basic operations (add, subtract, multiply, divide)
- [ ] Add comprehensive unit tests for the calculator module
- [ ] Create a README with usage examples and documentation
- [ ] Add error handling for edge cases (division by zero, invalid inputs)
- [ ] Create a command-line interface for the calculator

## Acceptance Criteria
- All code should be properly documented
- All tests should pass
- Code should follow Python best practices (PEP 8)
- Error handling should be comprehensive
- CLI should be user-friendly with clear help messages
