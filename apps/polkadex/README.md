# Polkadex DEX - Atlas Sphere Integration

Decentralized exchange powered by Polkadex technology integrated with Atlas Sphere blockchain.

## Features

- **Decentralized Order Book**: High-performance on-chain order matching
- **AMM Pools**: Automated market maker functionality
- **Cross-chain Trading**: Trade assets across multiple blockchains
- **Low Latency**: Fast order execution and matching
- **Non-custodial**: Users maintain control of their assets

## Development

```bash
npm install
npm run dev
```

Access at: http://localhost:3007

## Integration with Atlas Sphere

This DEX connects to the Atlas Sphere blockchain node at `ws://localhost:9944` and provides a decentralized trading interface.

## Port

Default: 3007
